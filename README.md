## Install as an app

DiceForge is an installable web app (PWA). Start the server with `npm start` and open `http://localhost:4173`, then use the **Install** button in the header or the **Info → Installable Web App** card.

- **Desktop (Chrome / Edge):** click the install icon in the address bar, or open menu ⋮ → *Cast, save, and share* → *Install page as app*.
- **Android (Chrome / Edge / Samsung Internet):** open menu ⋮ → *Install app* or *Add page to → Home screen*.
- **iPhone / iPad (Safari):** tap Share → *Add to Home Screen*.

The service worker keeps the app shell available offline. Balances, settings, and bets still require a live connection to the server and Crypto.Games.
