## Install as a web app

DiceForge ships as an installable PWA. Open the app over HTTPS (or localhost), then use the gold **⤓** button in the header or **Install DiceForge** on the Info tab.

- **Chrome / Edge (desktop & Android):** click **INSTALL APP** and confirm.
- **Safari (iPhone / iPad):** tap **Share → Add to Home Screen**.
- **Already installed:** the install controls hide automatically when the app runs in standalone mode.

The app shell loads offline; live rolls, account login, and balance data still require a connection.
